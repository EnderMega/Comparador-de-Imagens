# Comparador de imagens

Compara cada pixel de uma imagem com outro, verifica se elas são diferentes e gera uma imagem final mostrando o resultado. Se as imagens possuem tamanhos diferentes compara as intersecções.<br>
No momento aceita apenas `.ppm`.

---

## Compilar

```
chmod +x compilar
./compilar
```

## Uso

```./teste```
Entrar os caminhos *relativos* das imagens, tanto faz a ordem.
Escreve as imagens são diferentes e gera uma imagem `final.ppm` com as diferenças em vermelho por padrão.
